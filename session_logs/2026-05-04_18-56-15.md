This session consolidated the BERT sentiment workflow around `python_codes/Toaster_BERT.ipynb` and the reusable helper module in `python_codes/custom_functions.py`.

`Toaster_BERT.ipynb` now loads the toaster review data, deduplicates reviews to the most recent review per reviewer/product pair, loads the CardiffNLP Twitter RoBERTa sentiment model, runs the reusable sentiment helper on `RV_TRANS`, and then renames the helper's generic output columns from `SENTIMENT` and `SENTIMENT_SCORE` to `BERT_SENT` and `BERT_SCORE`. `custom_functions.py` contains the reusable sentiment utilities. It detects the best available torch device, maps that device to HuggingFace pipeline conventions, normalizes labels, cleans text values, resolves tokenizers, chunks texts that exceed the token limit, and batch-processes valid text rows. Invalid text values such as missing entries, very short strings, and punctuation-only strings remain missing in the output sentiment and score columns. The sentiment function is index-safe, so sampled or filtered DataFrames with nonconsecutive indexes are filled correctly. It also exposes configurable input and output column names, token limits, overlap, batch size, label mapping, and cleaning options.
